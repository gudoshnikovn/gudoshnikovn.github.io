# gudoshnikovn.github.io

The root of `https://gudoshnikovn.github.io/`. It serves `robots.txt`, which points crawlers to the sitemaps of the project sites, and the search-engine verification files. The project sites are published by their own repositories:

- [libphash](https://gudoshnikovn.github.io/libphash/) — perceptual image hashing library in C
- [python-libphash](https://gudoshnikovn.github.io/python-libphash/) — its Python binding
